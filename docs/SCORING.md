# 打分规则（v0.1 实现说明）

代码在 `src/scoring/`，参数集中在 `src/scoring/config.ts`。全部是固定规则，不调用 AI。本文是对 PRODUCT.md "打分算法（初稿）"的落地细化，所有数值都是初始假设，朋友试用后调整。

## 数据原则

- **打分**（四个维度）只用 `review_status = verified` 的成分。
- **安全相关**（硬性过滤、孕期提示、搭配冲突）也看 draft 成分，宁可多提示，结果中标注"成分数据未核对"。
- 不在成分库的成分和未核对的成分分开统计，合并显示为"有 N 个成分暂无数据"。
- 一个产品没有任何 verified 成分时，不出分数（显示无法评分）。
- 成分名匹配忽略大小写、多余空格，并使用成分库的 aliases。

## 第一步：硬性过滤（直接排除并说明原因）

| 条件 | 依据 |
|---|---|
| 怀孕 / 备孕 / 哺乳 | 含 `pregnancy_caution` 成分 |
| 正在用处方皮肤药 | 含 `rx_caution` 成分 |
| 想避开的具体成分 | 按名称匹配，库里没有的成分也能避开 |
| 想避开的成分类型（香精 / 酒精 / 精油） | 对应 risk_tags |
| 超出预算 | 见下方"预算" |
| 与在用产品严重冲突 | conflicts_with 标注 `:severe` |

用户档案中填写的想避开的成分（具体成分和成分类型）都走硬性过滤，直接排除。

另外，含 `pregnancy_caution` 成分的产品对所有人被动显示"孕期或哺乳期请注意"。

### 预算

- 预算题是"单件预算上限"，选项为 ≤ 12 USD、≤ 30 USD、不限（参数在 `src/scoring/config.ts` 的 `BUDGET_CAP_OPTIONS_USD`）。
- 产品存当地价格，用 `data/exchange_rates.csv`（美联储 H.10 汇率）换算成 USD 后与上限比较，等于上限的产品保留。
- 向用户展示预算选项时，把上限换算成用户当地货币，例如 ≤ 约 1,900 JPY（`budgetOptionLabel()`，1000 以上取整到百位，其余取整到个位）。
- 价格未知、汇率表没有该币种：不排除，只提示"未做预算筛选"。

## 第二步：四个维度

| 维度 | 权重 | 规则 |
|---|---|---|
| 需求匹配 | 50% | 每个困扰只要有一个 verified 有效成分（category = active）的 targets 覆盖就得分，得分 = 覆盖的困扰权重 / 总权重 × 100。面部困扰有排序，按 3/2/1 加权；头皮、头发是多选不排序，平均加权。成分在成分表中的位置不影响得分（去屑等有效成分通常含量约 1%，排在成分表后部）。产品表没有浓度字段，暂不做浓度加分 |
| 刺激风险 | 25% | 从 100 分起扣：fragrance、alcohol、essential_oil、strong_acid、sensitizer 每个标签扣 15 分（同一标签只扣一次）；每天洗头时 strong_cleanser 扣 15 分。敏感肌或头皮易痒扣分加倍；冲洗型产品（usage_type = rinse_off，品类默认值和逐个填写的规则见 DATA_SCHEMA.md）扣分减半，免洗型不变；使用方式未知时按免洗处理。两者可以叠加，例如敏感用户用洗发水：15 × 2 × 0.5 = 15。最低 0 分 |
| 证据强度 | 15% | 每个已覆盖的困扰取针对它的成分中证据最强的一个（A=100、B=70、C=40），再按困扰权重平均 |
| 环境适配 | 10% | 硬水城市：含螯合剂（functions 含 chelating）记 100，不含记 50。未设城市、城市数据未核对、水硬度未知或水质不硬，均记中性 50 并注明原因。湿度、紫外线、季节等接入天气接口后补充 |

- 用户没选困扰、或没有可评估证据的维度记为"不计分"，其余维度的权重重新归一化。
- 每个维度输出 0–100 分、高 / 中 / 低（≥70 / 40–69 / <40）和一句中英文原因。刺激风险维度分数高表示风险低。

## 第三步：搭配检查

- 一般冲突不扣分，显示提醒："建议分开早晚使用"。
- 严重冲突不推荐（见第一步）。
- 冲突关系在任一方成分的 conflicts_with 中写明即可，双向识别。

## 排序

可推荐的产品按综合分从高到低排列，其后是无法评分的产品，被排除的产品放在最后（附排除原因）。

## 问卷映射与就医提示

代码在 `src/profile/questionnaire.ts`。

- 头皮：头皮屑 → dandruff，痒 → scalp_itch，发红 → scalp_redness，掉发 → hair_loss，洗头当天变油 → scalp_oil。头皮易痒视为敏感。
- 头发：干枯毛躁 → frizz，分叉断发 → damage，扁塌 → flat_hair，打结 → tangling，褪色 → color_fade；做过染 / 烫 / 漂或常用热工具 → damage。
- 就医提示（结果页顶部建议看皮肤科医生）：头皮屑"伴红斑、反复不好"；掉发"短期大量或成片脱落"。只有选了对应困扰时，追问的答案才生效。
