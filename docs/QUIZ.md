# 洗护问卷（已实现）

代码：`src/pages/Quiz.tsx`（页面），`src/profile/questionnaire.ts`（答案 → 打分输入）。一屏一题，单选题选完自动进入下一题；可以返回修改，已填的答案保留。除最后一题"想避开的成分"需要明确选择（可选"没有，跳过"）外，每一题都可以跳过。答案只保存在浏览器本地。

细问只按需展开：选了头皮屑才问头皮屑类型，选了痒才问瘙痒程度，选了掉发才问掉发情况；只买护发素时不问头皮。

## "帮我判断"

规则在 `adviseCare()`，结果页显示建议和原因，用户可以直接切换洗发水 / 护发素 / 洗护搭配：

1. 已有满意的护发素 → 只换洗发水。
2. 没有干涩、打结、受损（染、烫漂、易断、高温造型）、卷发、粗发，也没选柔顺、滋润、减少毛躁、光泽、卷度清晰 → 只用洗发水；发丝偏细或想蓬松时说明"需要时选轻盈型护发素，只涂发尾"。
3. 其他情况 → 洗发水 + 护发素；受损且接受额外步骤时，建议每周加一次发膜（发膜数据整理中）。
